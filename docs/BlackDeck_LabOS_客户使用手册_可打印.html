01 / QUICK START

三步开始使用

打开 Cardputer-Adv，确认出现 BLACKDECK 主菜单。需要射频功能时，先在关机状态装好 Cap CC1101 与对应天线。
用 USB 数据线连接 RDK X5，确保 RDK 已开机、LabOS 服务已启动。连接前关闭 Arduino 串口监视器。
打开 LabOS 网页，进入「06 部署与诊断」，按「USB 一键通信自检」。显示 `ok: true` 后再开始采集。
首次访问：RDK 自身浏览器打开 http://127.0.0.1:8080。Windows 浏览器若不能直接访问，请按工程的《部署步骤》先打开 SSH 转发。

02 / CONNECTION

连接与 USB 自检

确认 Cardputer-Adv 已开机，Cap 扩展帽连接牢靠。
用具有数据功能的 USB 线连接 ADV 和 RDK X5 的 USB Host 接口。
在浏览器打开 LabOS，点击左侧「06 部署与诊断」。
点击「USB 一键通信自检」，查看下面的返回结果。
显示 ok: true、protocol: LAB5、board: Cardputer-Adv 等字段后，回到「01 总览与采集」，点击「读取设备状态」。

正常时应该看到什么

字段结果示例 / 判断
oktrue
protocolLAB5
firmware应有固件版本字符串

flash_bytes8388608（8 MB Flash）
hello_ms / info_ms显示本次实测往返耗时（不是固定值）
注意：通信自检只检查两次 USB 交互，不自动进行 WiFi、BLE、RF 或 NFC 实测。对应工具是否正常，需要继续执行下一页的单项测试。
03 / ACQUISITION

四类无线工具如何使用

WiFi 扫描

进入「01 总览与采集」→ 点击 WiFi → 完成后看最近一次结果与信道统计。无可见热点时允许 0 条。

BLE 广播扫描

进入「01 总览与采集」→ 点击 BLE → 查看地址、名称和 RSSI。设备名称仅供识别参考。

CC1101 接收

先安装对应天线 → 点击 Sub-GHz（433.92 MHz），或选择 315 / 868 / 915 MHz 按钮 → 查看 RSSI 采样。

NFC 标签识别

把自己的 NFC-A 测试标签靠近 Cap → 点击 NFC → 读取标签 UID 与可读 NDEF。未读到时可再次尝试。

每次采集后，先看这三处

右侧「最近一次采集结果」中的数据来源是否为 ADV_USB。
数据记录是否带有批次 ID 和时间。
是否出现真实测量值；RSSI 是dBm，RF 接收数据不是方向位置或宽带 SDR 波形。
天线操作：切换 315 / 433 / 868 / 915 MHz 前停止采集并更换匹配天线。不要把不同频段的测量用作同一频段的直接对比。
设备未找到：先返回「06 部署与诊断」重新执行通信自检；若自检成功但单项工具失败，记录该工具报错并检查扩展帽、标签或周边设备。
04 / ANALYSIS & SESSIONS

查看曲线与保存一次实验

查看测量结果

点击左侧 02 无线数据分析。
选择 RF RSSI / WiFi RSSI / BLE RSSI，查看曲线。
点击 更新数据，查看最新存储的样本。WiFi 信道图及设备档案位于页面下方。
如需导入自己的离线数据，在页面底部选择 CSV / PCAP 并点击 导入并分析。

新建、完成和导出一次实验

进入 03 实验管理，填写实验名称和测试条件，点击 创建实验会话。
返回 01 总览与采集，完成需要保存的数据测量。
进入 03 实验管理，选择该实验，会话数据可导出 CSV / 导出 JSON。
点击 打印报告，在浏览器打印窗口选择保存为 PDF。
全部结束后点击 结束当前会话。结束后的会话保留可查阅记录。
看来源标记：ADV_USB = 设备串口回传；imported = 手动导入文件；simulated = 演示数据。不同来源不要混写为真实测量。
05 / DISPLAY & AI

演示投屏与 AI 操作

在 RDK 上投屏演示

点击 05 全屏演示驾驶舱。
选择 数据库记录回放，展示已存的实验数据。
没有真实记录时，选择 视觉模拟演示，再按 全屏投影。
需要静止画面时点击 暂停动画；按 刷新记录 更新，退出全屏使用浏览器 Esc。
展示模式提醒：环形点位是装饰性排布，并不代表信号方位。数据库回放不等于实时接收，模拟展示不进入正式数据库。

使用 AI 分析助手

先完成一次实际采集或选择已有实验会话。
点击 04 AI 分析助手，输入问题，点击 分析数据。
如已配置 Whisper.cpp，可选择 WAV 文件，点击 转写 WAV，然后点击 用于提问。

Cardputer-Adv 本机动画

在 BlackDeck 主菜单按 V → 进入 Showroom / FX。
选择 Neon Radar、Matrix Rain、System Pulse 或 Signal Catcher；按键可退出。真实资源读数与演示动画会分别标明。
Whisper 与 Ollama 是可选功能，未安装时其他测量、记录和展示功能仍可使用。
06 / TROUBLESHOOTING

常见问题，直接处理

看到什么立即怎么做
USB 未连接 / 找不到串口检查 USB 数据线、RDK USB Host、ADV 是否开机；关闭其他串口软件后重试自检。
Permission denied让管理员将当前 RDK 用户加入 dialout 组，重新登录后再试。
协议不匹配确认 ADV 已烧录本工程 BlackDeck V2.2，RDK 正在运行 LabOS V5.2，未连接其他串口设备。
USB 自检通过，但 RF 无法接收停止采集，检查 Cap 安装与匹配天线，重新点击对应频段按钮。
NFC 识别不到标签将 NFC-A 测试标签贴近扩展帽天线区域，再点一次 NFC。
图表没有数据先完成采集，查看是否选错会话或协议类型；点击「更新数据」。
AI 无响应 / 模型报错返回主菜单，用「系统信息」查看剩余 Heap；记录报错反馈维护人员。
语音服务未配置不影响其他功能；需要管理员先部署 Whisper.cpp 及模型。
页面打不开确认 RDK 上服务仍运行；Windows 远程访问时保持 SSH 转发窗口打开。
遇到问题时请保存：网页上的错误提示、设备固件版本、失败工具名称，以及操作时间。不要仅凭动画推断传感器已工作。
