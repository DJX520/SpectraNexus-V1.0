14 / INTEGRATION RULES

开发与测试边界

基础工程不需要外置无线网卡，也不需要 BPU 推理模型。NFC 仅读取自有测试标签；CC1101 无主动发射；WiFi/BLE 只做基础发现。

单机模式保留 BlackDeck 及离线小模型。新增固件需要安装官方 M5 NFC 库，并进行实际编译与硬件验收。

RDK X5 运行 Linux；终端里使用 Bash 命令，不需要 PowerShell。
