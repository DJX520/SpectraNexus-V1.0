# V2.2 / V5.2 功能测试结果（2026-11-22）

## 当前确实执行过

- RDK Python 单元测试、HTTP API、异常帧测试、模拟串口：**26/26 通过**。
- Linux PTY 字节通道：模拟 Cardputer 固件端发送 LAB5 消息，验证 HELLO、INFO、WiFi 中文 SSID、NFC 空数据及关闭串口后离线状态，均通过。
- 前端 JavaScript `node --check` 两文件均通过。
- 浏览器静态布局（隔离离线预览）：1440 / 768 / 390 px 无横向溢出，脚本无异常；紫金主题与演示切换可交互。
- PDF 8 页已排版并渲染查看。
- 全部离线 AI 源码文件与 V5.1 源码对比 SHA-256 一致。
- 固件分区布局 0x10000 + 0x7E0000 到 0x7F0000，SPIFFS 到 0x800000。未删原始 AI 模型。

## 未执行的硬件验证（必须在实际设备上操作）

- Windows Arduino IDE 2.3.5 + ESP32 Core 3.3.7 的**新版固件完整编译/上传**；需核对实际固件小于 8,257,536 字节。
- Cardputer-Adv 与 RDK X5 的真实 USB CDC 握手、断线恢复与长时间稳定性。
- CC1101 各频段实际 RSSI、ST25R3916 NFC-A 读卡、WiFi/BLE 现场扫描；测试覆盖并不能说明测量精度已校准。
- 离线 AI 在实际 512 KB SRAM 环境的推理稳定性及触发条件。
- Whisper.cpp、Ollama 属于可选安装，未做当前设备测试。
