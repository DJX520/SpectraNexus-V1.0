针对物联网设备调试、无线通信测试、智能硬件研发与实验教学等应用场景，设计了一套基于 M5Stack Cardputer-Adv 与 RDK X5 的便携式多协议无线感知与边缘智能分析系统。  系统以Cardputer-Adv 为手持终端，搭载 Cap CC1101 无线扩展模块，集成 WiFi、BLE、Sub-GHz 射频、NFC 和红外等通信工具，实现无线设备发现、信号强度观测、标签信息读取及基础协议交互。通过自主整合的 BlackDeck 固件，设备具备独立操作、图形化交互和轻量级离线 AI 推理能力。  在此基础上，系统通过串口将手持终端与 RDK X5 连接，由 LabOS完成多源数据接收、实验记录、信号统计、异常筛查、可视化展示和报告导出，并提供可选的智能问答与语音分析能力。
